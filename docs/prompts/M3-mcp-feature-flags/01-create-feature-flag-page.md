Проанализируй постановку `docs/M3/feature-flags-spec.md`

Добавь в проект страницу с отображением состояния всех фича-флагов.

Состояние фича-флагов должно храниться в json файле на файловой системе.
Путь к файлу задается переменной окружения `FEATURE_FLAGS_JSON`. Значение по умолчанию `/tmp/features.json`

Backend должен предоставлять REST API методы для управления фича-флагами:
- листинг фича-флагов
- получение одного фича-флага
- изменение состояния фича-флага Enabled/Disabled
- изменение процента трафика 

Эти API методы должны использоваться со стороны frontend, а также они будут использоваться для реализации MCP сервера.

Сейчас MCP сервер реализовывать не нужно.
